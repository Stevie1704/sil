# SiL 0.2.1

This patch fixes the Linux native development archive's Debian bookworm
compatibility and adds the release install script.

## Supported machine class and determinism

Linux x86-64 with glibc 2.36 (Debian bookworm) or newer. The native archive
now comes from the same pinned bookworm toolchain as the runtime image.
Release verification runs the archive on both Ubuntu and bookworm and
rejects ELF imports above `GLIBC_2.36` or `GLIBCXX_3.4.30`.

The published 0.1.0 and 0.2.0 native archives require glibc 2.38 and
`GLIBCXX_3.4.32`, despite their release notes' bookworm support statement.
They are not replaced. Their runtime images already use bookworm and are
unaffected.

The determinism boundary is unchanged: the same compiled artifacts, Manifest
bytes and dependency versions on the same machine class produce identical
Recordings. The new toolchain produces new artifacts; bit identity with
earlier releases or across machine classes is not promised.

## Install script

The release attaches `install.sh`, which verifies checksums and installs
the wheel and native archive into a versioned user prefix. See
[getting started](../getting-started.md) for installation and platform
requirements.

## Compatibility

| Surface | Status in this release |
| --- | --- |
| Native participant C ABI | unchanged, `SIL_ABI_VERSION 1` |
| Clock region | unchanged; use the runner and shim of one release together |
| Manifest document | unchanged, version `1` |
| Step protocol | unchanged, protocols `1` and `2` |
| Recording contract | unchanged |
| Runner command line and exit codes | unchanged |
| Native schema-generation tool | unchanged |
| Python API | unchanged |
| Container entry point | unchanged |

## Run-impacting changes

- Manifest bytes: none.
- Manifest hashes: none.
- Run behavior: none.
- Exit-code classification: none.
- Recording bytes: none by design; cross-release bit identity is not promised.
