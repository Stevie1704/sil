# SiL 0.1.0

This release adds version and artifact identity reporting around the existing
Run contract. The release workflow prepends the source revision and exact
runtime image digest when it publishes the final notes.

## Supported machine class and determinism

This release is supported on Linux x86-64 with glibc at Debian bookworm level
or newer. The reference runtime is the pinned `python:3.13.7-slim-bookworm`
image used to build the release image. The guarantee is exact and bounded:
the same compiled artifacts, the same Manifest bytes, and the same dependency
versions on the same OS, CPU architecture, and libc produce a bit-identical
Recording. It does not promise bit identity across machine classes, and a
developer build is not the release artifact.

## Compatibility

These are compatibility promises; scheduler internals, diagnostic text,
development fixtures, and the container's internal filesystem are
implementation details.

| Surface | Status in this release |
| --- | --- |
| Native participant C ABI | `SIL_ABI_VERSION 1`; unchanged |
| Manifest document | version `1` is supported; no Manifest compatibility behavior changed |
| Step protocol | protocol `2` is supported; protocol `1` remains accepted |
| Recording contract | uncompressed MCAP, virtual timestamps, and the Manifest hash remain the contract; unchanged |
| Runner command line | `sil-run`, `--version`, and `--build-info` report the release identity; run behavior and exit-code meanings are unchanged |
| Native schema-generation tool | the installed `silschema` command and generated-header contract are shipped as release interfaces |
| Python API | the documented `sil.*` modules and `sil-*` entry points ship at version `0.1.0`; unchanged |

## Run-impacting changes

- Manifest bytes: none.
- Manifest hashes: none.
- Run behavior: none.
- Exit-code classification: none.
- Recording bytes: none.
