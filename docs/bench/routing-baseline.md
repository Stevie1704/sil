# Routing baseline — raw results

Generated by `tools/bench_routing.py`; do not edit by hand.
The procedure, the reading, and the go/no-go inputs are in
[large-message-routing-baseline.md](large-message-routing-baseline.md).

- machine: macOS-26.6.2-arm64-arm-64bit-Mach-O
- messages per run: small 200, camera 50
- publish period: 10 ms (100 Hz)
- wall-clock repeats per row: 5 (median reported)
- payload sizes: small 16 B, camera 2764808 B

Copy columns are counts reported by the instrumented kernel, not
figures inferred from timing. A Recording row is I/O-bound: its
wall-clock follows the host's page-cache state and is not comparable
across machines or across days. Its kernel user time is.

## Fixed cost control

A one-Message Run of the same shape, with Recording off, costs 7.4 ms wall-clock. Every µs/message figure below still carries that fixed cost once. It nets the Recording-off rows only, and no Process row: a Process row also pays its participant's interpreter start-up.
