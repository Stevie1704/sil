# Retained native qualification evidence

This is the final qualification snapshot from
[native Linux run 35705741334](https://github.com/Stevie1704/sil/actions/runs/35705741334),
implementation commit `7561af5`, merge snapshot
`09fab1eb618c873aa07b0f957f4f4b305c635b84`. Superseded development snapshots are
available in Git history. Consolidation changes the storage format, not the
observations, Manifests, Recordings or artifact identities.

| Retained files | What they establish |
| --- | --- |
| `*.fmpy.csv` | Independent initialization, inputs, pre-step and post-step values, FMI flags and termination |
| `*.sil-lifecycle.csv` | Importer initialization, every communication point and successful termination at 1.0 s |
| Case Manifests, both `*-{1,2}.mcap` files and provenance | Exact Runs and directly verifiable per-Manifest byte determinism |
| `results.json`, `rebuild.json` | Both Recording hashes/exit codes and both clean-build hashes per FMU |
| `archives.json`, `schema-identity.json`, `*.ldd.txt` | Schema validation, actual symbols/capabilities and linked dependencies |
| `environment.json`, `image-id.txt` | Source revision, runtime, runner identity and predeclared tolerances |
| `null-resource-initialization.json` | Expected resource-path rejection and its exit code |

The **one authoritative FMU pair** and their source/exporter/license identities
live in [`tests/fixtures/pythonfmu3/`](../../../tests/fixtures/pythonfmu3/). The
ordinary regression tests use those same archives. Their SHA-256 values match
this snapshot's archive and rebuild reports; no CI download is needed to verify
them. The archives are unchanged bytes from the native run above.

CSV traces contain every field from the original lifecycle JSON, with arrays
expanded into named columns. `input.*`, `before.*` and `output.*` use the model's
SI units; times are seconds. Empty cells mean the field was absent in that
phase, not zero. Boolean FMI flags are `true`/`false`. Conversion was checked by
reconstructing every original row, including exact floating-point values.
The kernel Recording is retained as MCAP; its redundant decoded JSON is omitted.
Use `sil.recording.read_records` and the Manifest schemas to decode it.

Full raw JSON traces, empty logs and routine console output remain in CI
artifacts and are generated by `run-proof.sh`. They are not committed on each
execution. Keep this single curated snapshot unless deliberately replacing its
qualification baseline; do not add a new directory for each development pass.
